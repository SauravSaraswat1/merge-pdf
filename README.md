# Merge PDF Online

Need to combine multiple PDF files into a single document?

This repository provides useful information, tips, and resources for merging PDF files.

## What is PDF Merging?

PDF merging is the process of combining two or more PDF documents into a single PDF file.

For example, you may want to combine:

* Multiple assignments
* Project documents
* Scanned documents
* Business reports
* Invoices
* Study notes
* Application documents
